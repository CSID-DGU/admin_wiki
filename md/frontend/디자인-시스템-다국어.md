# 디자인 시스템과 다국어

화면 부품(DECS 디자인 시스템), 색·간격 규칙, 한국어·영어 문구를 다루는 법입니다.

## 1. DECS 디자인 시스템

`src/design-system/`은 이 저장소 안에 있는 자체 부품 모음입니다. 외부 UI 라이브러리를 쓰지 않습니다. 생김새는 AWS의 Cloudscape 디자인 시스템을 본떴고, 강조색만 학교 주황색으로 바꿨습니다.

부품은 **반드시 `design-system/index.js`에서** 가져옵니다.

```jsx
import { Button, Modal, Table, StatusIndicator } from "../../design-system";
```

| 분류 | 부품 |
| --- | --- |
| 알림·상태 | `StatusIndicator`, `Badge`, `Alert`, `Flashbar`, `ProgressBar` |
| 입력 | `Button`, `ButtonDropdown`, `FormField`, `Input`, `Select`, `ExpandableSection` |
| 데이터 | `Table`, `Cards`, `KeyValuePairs`, `Pagination` |
| 배치 | `Header`, `Container`, `Tabs`, `Modal`, `Wizard` |
| 화면 틀 | `AppLayout`, `SideNavigation`, `TopNavigation`, `BreadcrumbGroup` |
| 기타 | `Icon`(Heroicons 기반), `useMediaQuery`와 `NARROW_QUERY`·`PHONE_QUERY` |

필요한 부품이 없으면 화면 안에서 비슷한 것을 새로 만들지 말고 `design-system/components/` 아래에 추가한 뒤 `index.js`에 내보냅니다. 두 화면 이상에서 쓸 것이 아니라면 기존 부품을 조합합니다.

### 자주 쓰는 약속

| 부품 | 약속 |
| --- | --- |
| `Input`, `Select` | `onChange`가 이벤트가 아니라 **값**을 넘긴다 |
| `Button` `variant` | `primary`, `normal`, `link`, `inline-link`, `icon` 중 하나 |
| `StatusIndicator` `type` | `success`, `error`, `warning`, `info`, `in-progress`, `loading`, `pending`, `stopped` 중 하나. 신청·Pod 상태는 직접 고르지 말고 `mapPodStatus()`의 결과를 쓴다 |
| `ProgressBar` | 사용률처럼 끝나지 않는 값에는 `status`를 주지 않는다. `error`를 주면 막대와 수치가 사라진다. 색만 바꾸려면 `tone`을 쓴다 |
| `Modal` | `dismissible={false}`면 바깥 클릭·Esc로 닫히지 않는다. 반드시 끝내야 하는 입력에만 쓴다 |

## 2. 토큰

색, 간격, 글꼴, 모서리, 그림자는 `design-system/tokens/*.css`에 CSS 변수로 있습니다. 코드에 값을 직접 쓰지 않고 변수를 씁니다.

| 파일 | 변수 예 | 비고 |
| --- | --- | --- |
| `colors.css` | `--decs-brand-500`, `--decs-status-success`, `--decs-text-secondary` | 원색(`--decs-grey-600`)보다 뜻 이름(`--decs-text-secondary`)을 먼저 쓴다 |
| `spacing.css` | `--decs-space-xs`(8px) ~ `--decs-space-xxxxl`(48px) | 관리자 표는 촘촘하게, 사용자 화면은 넉넉하게 같은 눈금에서 고른다 |
| `typography.css` | `--decs-font-base`, `--decs-font-mono` | Open Sans + Noto Sans KR, 코드는 JetBrains Mono. Google Fonts에서 받는다 |
| `radii.css`, `effects.css` | 모서리, 그림자, 전환 | |

```jsx
<div style={{ marginBottom: "var(--decs-space-m)", color: "var(--decs-text-secondary)" }}>
```

Tailwind도 함께 씁니다. `src/index.css`가 Tailwind의 `brand-*` 색을 DECS 강조색 변수에 묶어 두었으므로 `bg-brand-500`처럼 쓸 수 있습니다. 로그인·404 같은 오래된 화면에 Tailwind가 많이 남아 있고, 새 화면은 DECS 부품과 토큰을 먼저 씁니다.

### 화면 폭

| 기준 | 값 | 바뀌는 것 |
| --- | --- | --- |
| `NARROW_QUERY` | 1023px 이하 | 옆 메뉴가 접힌다 |
| `PHONE_QUERY` | 639px 이하 | 여러 열이 한 열로 쌓인다 |

새 화면은 휴대폰 폭에서 글자가 쪼개지거나 가로로 넘치지 않는지 브라우저 개발자 도구의 기기 모드로 확인합니다.

## 3. 린트 규칙

`eslint.config.js`가 위 약속을 검사합니다. `src/design-system/` 밖의 `.jsx` 파일에 아래가 있으면 **경고**를 냅니다.

| 경고 | 고치는 법 |
| --- | --- |
| `Import DECS components from the design-system index.` | `design-system/components/...` 대신 `design-system`에서 가져온다 |
| `Raw hex color — use a DECS color token.` | `#f68313` 대신 `var(--decs-brand-500)` |
| `Raw px value — use a DECS spacing token.` | `"16px"` 대신 `var(--decs-space-m)` |
| `Use a DECS font token.` | `font-family`를 직접 쓰지 않는다 |
| `Invalid DECS Button variant.` / `Invalid DECS status type.` | 1절 표의 값 중에서 고른다 |

경고는 CI를 막지 않지만, 새로 쓰거나 고친 줄에서는 경고를 남기지 않습니다. 오류로 막히는 것은 쓰지 않는 변수(`no-unused-vars`, 대문자로 시작하는 이름은 예외)와 React Hooks 규칙입니다.

## 4. 다국어

화면 문구는 `src/locales/ko.json`과 `src/locales/en.json`에 있고, `react-i18next`로 꺼내 씁니다.

```jsx
const { t } = useTranslation();
<Header>{t("shell.dashboard")}</Header>
<span>{t("container.daysLeft", { count: 3 })}</span>
```

| 항목 | 내용 |
| --- | --- |
| 기본 언어 | 한국어. 상단의 `EN` 버튼으로 바꾸면 `localStorage`에 기억한다. 브라우저 언어는 보지 않는다 |
| 키 구조 | 첫 단계가 화면·영역 이름(`common`, `auth`, `shell`, `status`, `wizard`, `container`, `change`, `restart`, `validation`, `ds` …) |
| 복수형 | `count`를 넘기는 문구는 한국어에 `키_other` 하나, 영어에 `키_one`과 `키_other` 둘을 둔다 |
| 디자인 시스템 문구 | `ds.*`. 부품 안의 "복사", "선택하세요" 같은 문구 |
| `<html lang>` | 언어를 바꾸면 `i18n.js`가 함께 바꾼다. 화면 읽기 프로그램과 브라우저 번역이 이 값을 본다 |

### 문구를 더할 때

1. 두 파일에 **같은 키**를 넣는다. 한쪽에만 있으면 영어 화면에서 한국어가, 또는 키 이름이 그대로 보인다.
2. 서버에서 받은 오류 문구(`error.message`)는 번역하지 않고 그대로 보인다. Admin BE가 한국어로 보낸다.
3. 날짜는 `Intl.DateTimeFormat(i18n.resolvedLanguage, …)`로 현재 언어에 맞춰 만든다.

`pages/admin/`의 관리 화면들과 `AuthContext`의 창에는 아직 한국어가 코드에 직접 들어 있어, 영어로 바꿔도 그 부분은 한국어로 보입니다. 그 화면을 고칠 때 손댄 문구부터 `locales`로 옮깁니다.

### 언어를 바꾸면 다시 불러온다

`useDecsUserData`는 상태 이름, 만료일 같은 문구를 불러올 때 만들어 두므로, 언어가 바뀌면 데이터를 다시 불러와 새 언어로 다시 만듭니다. 새 데이터 훅도 화면 문구를 미리 만들어 둔다면 같은 방식으로 언어를 의존성에 넣습니다.
